Demonstrations

Start python3 launch.py from this extracted folder to use the browser apps.

Return to the companion index.

The Panda commands below need the Drake environment. Each web page opens without running anything: a replay waits for Step, and the IK page solves only when the target changes. Open the printed address; stop with Ctrl+C.

Prediction versus FK on the Panda

python launch.py gn-ik-replay

Hard-target IK and its solver results

python launch.py ik-nlp

The Panda elbow limit and multiplier

python launch.py constrained-ik-replay

Hard-target rail and joint-bound multiplier events

python launch.py ik-nlp-al-replay
